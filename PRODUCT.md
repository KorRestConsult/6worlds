# Restaurant Academy — продуктовый костяк

## Центральная гипотеза

Ресторан платит не за LMS и не за «красивое приложение». Он платит за сокращение времени, за которое официант начинает уверенно знать меню и продавать его без постоянного контроля управляющего.

## Ядро продукта

### 1. Учить
- кухня;
- бар;
- карточка блюда/напитка;
- состав;
- вкус;
- аллергены;
- что предложить в пару;
- фраза для допродажи.

### 2. Проверять
- короткие тесты;
- вопросы по ситуациям гостя;
- повтор слабых тем;
- итоговая аттестация.

### 3. Мотивировать
- XP;
- уровни;
- серия дней;
- рейтинг внутри смены/ресторана;
- награды за подтверждённое знание.

### 4. Контролировать
- сотрудник;
- процент кухни;
- процент бара;
- результаты тестов;
- слабые категории;
- готовность к самостоятельной смене.

## Пакеты — пока рабочая гипотеза

### Start
Меню + карточки + тесты + XP + рейтинг + базовый кабинет управляющего.

### Pro
Start + адаптация новичка + стандарты сервиса + чек-листы + аналитика + AI по меню и стандартам.

### Brand / Multi-location
Pro + индивидуальный UI + несколько заведений + роли + расширенная аналитика + интеграции + отдельная база знаний/AI + white-label.

## Метрики для собственника

- время до допуска сотрудника к самостоятельной смене;
- % знания кухни;
- % знания бара;
- доля сотрудников, прошедших аттестацию;
- динамика знаний по неделям;
- слабые позиции меню;
- вовлечённость в обучение.
