# Restaurant Academy — Demo

Нейтральный демонстрационный MVP для ресторанов. Отдельное ядро продукта, собранное для проверки главной гипотезы: официант изучает меню кухни и бара, подтверждает знания тестами, получает XP/уровень/место в рейтинге, а управляющий видит реальный прогресс команды.

## Фокус MVP

1. Официант учит меню кухни и бара.
2. Каждая позиция содержит состав, вкус, аллергены, пару и фразу для продажи.
3. Сотрудник проходит короткие ситуационные тесты.
4. За подтверждённые знания получает XP, уровень и место в рейтинге.
5. Управляющий видит прогресс команды, кухню/бар и слабые зоны.

## Что уже работает

- мобильная и десктопная верстка;
- режим «Официант»;
- режим «Управляющий»;
- меню кухни и бара;
- карточки позиций;
- тест из 5 вопросов;
- начисление XP;
- уровни и рейтинг;
- сохранение XP и роли через localStorage;
- PWA manifest + service worker.

## Что намеренно не включено в первый MVP

- настоящий backend и регистрация;
- импорт реального меню;
- AI;
- чек-листы;
- график смен;
- касса / iiko;
- полноценная админка.

Сначала проверяем одну вещь: готовы ли рестораны платить за систему, которая ускоряет знание меню и делает его измеримым.
